# HTML Audio and Video Player

freeCodeCamp Responsive Web Design lab. A page with two sections: one video, one audio.

## What this is

- `h1` and two `section`s
- Video gets a `<source>` child: `src` is the file address, `type` is the kind
- Audio gets `src` on the `audio` tag, no `<source>` child
- `controls` on both so a play bar shows

## Live

Completed in the freeCodeCamp in-browser editor (Build an HTML Audio and Video Player).
