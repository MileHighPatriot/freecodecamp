# HTML Video Player

freeCodeCamp Responsive Web Design workshop. A page with a `<video>` element that can play several file kinds so the browser can pick one it supports.

## What this is

- Opening `video` tag with `width`, `controls`, `loop`, `muted`, and `poster`
- Multiple `<source>` children: `src` is the file address, `type` is the kind (`video/mp4`, `video/webm`, `video/ogg`, `video/quicktime`)
- Poster URL stays on `<video>`, not on `<source>`
